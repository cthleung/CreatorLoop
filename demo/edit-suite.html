What if my edit suite worked like this?

Nothing in my loop is really about prose, so this page carries it over to video. As a filmmaker, what I want is the thing I already have in my code editor, an assistant editor with hands, which comes back with a plan and lets me keep the taste. The example is the one from beyond-text.md, a scene where the reveal comes too early, and every step links back to the part of the tangerine drive replay it's built on.

ConceptNone of this software exists yet. The frames are line drawings, the timeline's simplified, and the scene is an illustration. The replay is the part that really happened.

Step 7 of 7 The agentMe

Remember this one, forget that one

The calls get kept with enough context to be useful later, and every preference it learns points back at the decisions that taught it. Approved edits become examples, and reverted ones become boundaries, which is really the same split as my pass and fail lines. So when a preference turns out to be for 1 scene only, I take it back like any other commit, and the edits it came from stay in that cut.

PrincipleIf I've told it once, I shouldn't have to tell it again. If I take it back, it's gone.

The one I'd watch over time is whether the same correction stops coming back. My writing loop already keeps its rulings this way, as rules and test pairs in git, so taking one back is a revert (taste-memory.md).

Where does this come from?

Every piece of this maps onto something that already works for me in text, and the tangerine drive replay shows that version step by step, from the record. The longer write-up is beyond-text.md, including what I'd train first (the agent's decisions, before any pixels).

The history part grew out of a pain point in my own workflow. I run several AI chats at the same time across 2 computers, and even as a software engineer I couldn't be bothered to untangle the git by hand, so I wrote skills that do it for me (tree-triage and session-commit, plus the worktree-handoff plugin). If I don't want to remember git commands, I'm pretty sure a creator doesn't either. That story's in version-control.md.
